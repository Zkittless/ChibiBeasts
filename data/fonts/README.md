# Field Journal display font

`Cinzel.ttf` is an unmodified copy of Google Fonts' Cinzel variable TrueType
font. It is bundled for the battle headings and companion names so Railway
does not need a system font or network font service. Numeric values use
Pillow's bundled face, with its own measured bounds.
